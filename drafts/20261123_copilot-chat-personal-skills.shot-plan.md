- 前提: 対象の Copilot ライセンス（公式ドキュメントでは Microsoft Copilot (Premium)）があり、対象環境で personal skill をアップロード出来ることを確認する。社内のアップロード規則と必要権限を事前確認し、秘密情報を含めない。撮影準備として記事内のコードをローカルの SKILL.md に保存し、架空の会議メモの共通入力を用意する。この下書き作成時点では実機未操作で、画像も SKILL.md の実ファイルも作成していない。検証日時と利用環境（ライセンス、選択したモデルなど）を記録し、掲載する結果はその時点・環境での動作であり、読者の環境で同じ動作を保証しない旨を記事に残す。日本語 UI ラベル、インストール済みスキルの選択位置、自動呼び出しの設定位置・ラベル、スキル使用を示す表示は撮影時に確認し、明示選択と自動呼び出し設定それぞれの開始位置・操作経路を記事に追記する。対象の操作や設定が見つからない場合は未確認として該当手順を中止し、代替画面の合成はしない。使用の有無を UI で判別出来ない場合も未確認とし、出力だけから断定しない。自動 ON/OFF 比較は新しいチャット、明示選択なし、記事の共通入力を完全一致で使用し、モデルなど選択可能な条件をそろえる。
